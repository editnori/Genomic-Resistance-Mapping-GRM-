## Status vocabulary

A request can have different states for different stages. Do not collapse these into one percentage:

- **Implemented:** source exists at the stated scope.
- **Executed:** the intended inputs were processed.
- **Verified:** named checks or receipts passed.
- **Integrated:** reachable through the maintained application or release path.
- **Published:** present in the current public release.
- **Answered:** an explanation or artifact was delivered; this does not imply implementation.
- **Partial:** part of the request remains undone.
- **Hard stopped:** an explicit refusal blocks rerouting or resumption.
